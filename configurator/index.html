Servos on one PCA9685. Power the servo rail from a separate 5V supply.

You set the closed and thrown positions after the board is running, not here.

Flash the board, then open http://<board-name>.local in Chrome or Edge (the name you set on the Board page). Each turnout has sliders for the straight and diverging ends. Move them until the point closes without straining. The ESP saves those positions, so you can adjust them later without downloading a new YAML. Travel time on this page is only how fast the throw moves.
