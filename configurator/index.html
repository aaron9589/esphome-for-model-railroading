Expanders (MCP23017)

An expander adds 16 sensor pins over I2C. Use one when the ESP runs out of pins. Wire a detector to an expander pin and GND, the same as an ESP pin. It can share a PCA9685 board's SDA and SCL pins, or have its own, and its sensors are listed under it.

Turnouts

Servos for the turnouts, with optional fascia buttons and a remote lock.

You can generally only run 3-4 servos this way. They take power from the ESP. More than that needs an external supply, which is why a PCA9685 is used to scale up.

No turnouts yet. Skip this if the board only watches the track.

PCA9685 boards

A PCA9685 drives up to 16 servos over I2C, with the servos on their own 5V supply rather than the ESP's. Use one for more than 3-4 servos. Each board has its own SDA and SCL pins, and its turnouts are listed under it.

Signal Masts

Each mast is its own LED strip, or one pin per lamp. List its lamps from the top down, then set what each aspect shows.

No signal masts yet. Skip this if the board has no signals.

JMRI

              

                
1 · MQTT connection

                

                  Once per JMRI profile. In Edit → Preferences → Connections, add a connection with
                  System manufacturer MQTT and System connection MQTT Connection.
                

                
    
                  
  • IP Address/Host Name: the broker from this board's settings, usually layout-mqtt.local. TCP/UDP Port: 1883.
    • 
                  
  • Connection Prefix: M. The file below names everything MS…, MT…, and IF$mqm…, which needs that prefix.
    • 
                  
  • Tick Additional Connection Settings. Channel is put in front of every topic JMRI uses. Set it to trains/ to match the board's topics. New JMRI versions leave it blank, and older ones used /trains/, with a leading slash. Both miss the board.
    • 
                  
  • Leave the turnout, sensor, and signal mast topics as they are (track/turnout/{0} and so on). {0} is the hardware address, the part of the system name after MT or MS.
    • 
                

                
Save, then restart JMRI.
